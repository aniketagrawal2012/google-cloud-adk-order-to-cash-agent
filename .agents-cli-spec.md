# Agent Spec: Enterprise Order-to-Cash & Supply-Chain ADK Agent

## Overview
An enterprise-grade Order-to-Cash (O2C) and Supply-Chain operations agent built with Google Agent Development Kit (ADK), deployed to Vertex AI Agent Runtime (Agent Engine), and registered with Gemini Enterprise. It audits purchase order 3-way match discrepancies, checks real-time regional hub inventory, calculates financial SLA exposure, and executes atomic compensating sagas with deterministic pre-LLM Sensitive Data Protection (SDP) and O(1) SHA-256 loop-breaking guardrails.

## Example Use Cases
1. **3-Way Purchase Order Audit & Pre-LLM Redaction**: Audit `PO-4500019280` for SKU `SKU-7740-EU`, verify ERP variance, check Rotterdam/Frankfurt hub inventory, calculate financial penalty exposure, and ensure restricted fields (`vendor_bank_iban`, `swift_routing_code`, `confidential_margin_floor`) are redacted before entering the LLM context window.
2. **Compensating Saga Rollback under Downstream Carrier Fault**: Execute a 3-step remediation saga for `PO-4500019280` when the downstream freight carrier API returns `HTTP 503`, verifying that Cloud Spanner reverse compensation unlocks warehouse stock and leaves `0` orphaned writes.

## Tools Required
- `verify_erp_purchase_order`: Queries SAP/ERP 3-way match ledger for PO status, quantities, and vendor metadata.
- `check_spanner_hub_inventory`: Queries Cloud Spanner regional inventory hubs for safety stock and available transfer units.
- `calculate_financial_exposure`: Queries BigQuery financial ledger for SLA penalty rates and margin exposure.
- `execute_spanner_compensating_saga`: Executes atomic multi-step remediation with automatic reverse-order rollback on fault.

## Constraints & Safety Rules
- Never expose `vendor_bank_iban`, `swift_routing_code`, or `confidential_margin_floor` to the LLM context window (`after_tool_callback` deterministic masking).
- Halt identical tool-call retry loops at `k = 3` within a sliding window of `W = 6` (`before_tool_callback` SHA-256 digest check).
- Guarantee `0` orphaned writes on partial failures via reverse saga compensation.

## Success Criteria
- `custom_response_quality` >= 4.0 / 5.0
- `sdp_zero_leakage_check` == 1.0 (zero unredacted IBAN/SWIFT values in response)
- `agent_turn_count` >= 1
